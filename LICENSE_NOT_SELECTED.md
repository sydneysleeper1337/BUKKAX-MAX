# License not selected

BUKKAX пока не получает open-source лицензию автоматически.

Если репозиторий публичный, но лицензии нет, это **не означает**, что любой человек получает право копировать, изменять и распространять код.

Варианты:

- **без лицензии** — удобно для портфолио / демонстрации;
- **MIT** — простая разрешительная лицензия;
- **Apache-2.0** — разрешительная лицензия с более подробными условиями;
- **GPL-3.0** — производные работы должны сохранять GPL.

Перед добавлением LICENSE выбери модель распространения, которая тебе нужна.
